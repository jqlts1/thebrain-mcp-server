# Returns details about the active user's TeamBrain Organization members

**接口路径:** `GET /users/organization`

**描述:** Returns details about the active user's TeamBrain Organization members

## 参数列表

该接口不需要参数。

## 响应列表

| 状态码 | 描述 |
| :--- | :--- |
| 200 | Returns details about the TeamBrain Organization members |
| 401 | If the API Key is missing or invalid |
| 404 | If the user is not found. |
